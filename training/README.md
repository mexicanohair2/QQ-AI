# Quantum AI — подготовка обучающих данных

Здесь начинается собственный контур обучения. Сейчас добавлен небольшой набор оригинальных примеров и валидатор формата. Никакие веса модели ещё не обучены и не изменены.

## Формат данных

Одна JSONL-строка — один диалог с массивом messages. Первый ход user, последний assistant. Тексты должны быть оригинальными, проверяемыми и полезными. Не добавляйте персональные данные, секреты, приватные переписки или копии чужих датасетов.

## Проверка

Запустите `npm run train:data:check`.

## План обучения

1. Собрать и дедуплицировать авторский русскоязычный корпус.
2. Разметить точность, полноту, ясность, следование инструкциям и безопасность.
3. Разделить train/validation/test без пересечения.
4. Зафиксировать лицензии и происхождение внешних источников.
5. Сравнить базовую Qwen с адаптацией LoRA на отложенной выборке.
6. Обучить адаптер на GPU-сервере и сохранить воспроизводимый отчёт.
7. Проверить регрессии до подключения новой версии к сайту.

JSONL сам по себе не обучает модель. Для обучения нужны базовые веса, вычисления на GPU и независимые контрольные тесты.
