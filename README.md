# QQ AI

QQ AI — независимый прототип мобильного ИИ-чата. Сейчас реализован интерфейс, история диалогов и локальный демонстрационный провайдер ответов.

## Текущий статус

**Первый запрос уже можно отправить в демонстрационном режиме.** Настоящая языковая модель пока не подключена: ответы не генерируются Qwen или облачным ИИ, а только подтверждают получение введённого текста.

В этой версии доступны:

- создание, выбор и удаление диалогов;
- отправка сообщения клавишей Enter (Shift+Enter добавляет новую строку);
- остановка ответа и повтор после ошибки;
- локальное сохранение истории в IndexedDB браузера;
- адаптивный интерфейс для телефона и компьютера;
- видимый индикатор демонстрационного режима.

Текст сообщений не отправляется на inference-сервер: подключённый mock provider работает в браузере. История хранится в IndexedDB текущего браузера и сама по себе не синхронизируется между устройствами.

## Запуск

Требуется Node.js 24 (либо версия не ниже 22.12).

```bash
npm ci
npm run dev
```

Проверки перед публикацией:

```bash
npm test -- --run
npm run typecheck
npm run build
```

## Архитектура

- `src/features/chat/chatReducer.ts` — чистые переходы состояния чата.
- `src/features/chat/useChat.ts` — жизненный цикл диалогов, отправка, отмена и повтор ответа.
- `src/features/chat/storage.ts` — проверяемое локальное хранение в IndexedDB.
- `src/features/chat/provider.ts` — контракт провайдера генерации.
- `src/features/chat/mockProvider.ts` — демонстрационная реализация без сетевых запросов.
- `src/components/` — интерфейс чата и история.

Будущая локальная модель Qwen и облачный провайдер будут отдельными реализациями интерфейса `ChatProvider`. Секреты облачных провайдеров не должны попадать в клиентскую сборку. Локальная модель не будет считаться поддерживаемой, пока её производительность и стабильность не проверены на реальных целевых телефонах.

## Безопасность зависимостей

Полный npm-аудит сейчас показывает предупреждения в цепочке dev-инструментов, связанные с upstream advisory для `picomatch`. Эти пакеты используются только при разработке, тестировании и сборке и не включаются в runtime сайта. Проверка production-зависимостей выполняется отдельно в CI. Подробности и ограничения зафиксированы в [отчёте аудита](docs/security/dependency-audit.md).

## Границы текущей версии

- Нет настоящего ИИ-ответа, Qwen, облачного inference или голосового режима.
- Нет регистрации, общей QQ-учётной записи, межустройственной синхронизации или лимитов.
- Нет интеграции с QQCross.
