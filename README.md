# QQ AI

Независимый онлайн ИИ-помощник. Репозиторий: `mexicanohair2/QQ-AI`.

## Текущий статус

- Mobile-first веб-интерфейс чата.
- История диалогов хранится локально в браузере.
- Потоковая выдача через серверный API-маршрут.
- Серверный адаптер совместим с OpenAI Chat Completions API; по умолчанию настроен на Qwen через DashScope.
- API-ключ хранится только в серверной переменной окружения.
- Подготовлен небольшой авторский seed-набор и проверка JSONL для будущего обучения.

## Запуск и публикация

Проект использует Vite + React + TypeScript и рассчитан на публикацию в Vercel, поскольку GitHub Pages не исполняет серверный API-маршрут.

Переменные окружения в Vercel:
- `QWEN_API_KEY` — секретный ключ провайдера (обязателен для ответов модели).
- `QWEN_BASE_URL` — необязательный URL OpenAI-совместимого API; по умолчанию DashScope International.
- `QWEN_MODEL` — необязательное имя модели; по умолчанию `qwen-plus`.

Модельные веса загружаются и обслуживаются на стороне провайдера. Пользователь не скачивает их на телефон. Пока секрет не настроен, API возвращает понятную ошибку вместо бесконечной загрузки.

## Обучение Quantum AI

См. `training/README.md`. Текущий набор — только стартовые авторские примеры, не обученная модель. Настоящее обучение потребует базовых весов, GPU-вычислений, расширенного корпуса и независимой оценки.

## Проверки

- `npm run typecheck`
- `npm run build`
- `npm run train:data:check`

Перед объявлением сайта опубликованным нужно подключить репозиторий в Vercel, задать серверный ключ и проверить production URL. Не добавляйте секреты в исходники или GitHub.
