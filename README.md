# QQ AI

QQ AI — независимый мобильный ИИ-помощник. Проект развивается отдельно от QQCross.

## Режимы работы

- **Онлайн:** запросы идут через защищённую серверную функцию напрямую к Cerebras Inference API. Vercel AI Gateway не используется.
- **Офлайн (режим по умолчанию):** Qwen2.5-0.5B запускается на устройстве через WebLLM и WebGPU. Первую загрузку нужно выполнить один раз при подключении к интернету.
- Офлайн-модель кэшируется в IndexedDB. После успешной загрузки повторно скачивать её при каждом переключении не нужно, пока браузер не очистит данные сайта.
- Для офлайн-загрузки нужен совместимый WebGPU-браузер, свободная память и интернет только на время первой загрузки.

## Точные вычисления\n\n- Отдельный безопасный калькулятор обрабатывает простую арифметику, проценты, скидки и сокращение целочисленных отношений без передачи вычислений языковой модели.\n- Выражения разбираются собственным парсером; `eval` не используется.\n\n## Облако и память

- Supabase Auth — вход по электронной почте.
- История диалогов, настройки памяти и оценки ответов хранятся в Supabase.
- Row Level Security ограничивает доступ владельцем строк.
- Память выключена по умолчанию. Пользователь сам добавляет то, что QQ AI может учитывать.
- Оценки ответов сохраняют только рейтинг, без копирования полного запроса/ответа в отдельный датасет.
- QQ AI не переобучает базовую модель на переписке. Персонализация через явную память и обратную связь — отдельный механизм.

## Облачный ИИ

- Серверный обработчик вызывает `https://api.cerebras.ai/v1/chat/completions` напрямую.
- Обязательная переменная Vercel: `CEREBRAS_API_KEY` (тип Sensitive/Encrypted, для Preview и Production). Её значение никогда не передаётся в браузер.
- Необязательная переменная `CEREBRAS_MODEL`; по умолчанию используется `zai-glm-4.7`.
- У Cerebras заявлены стартовые кредиты $5 после регистрации; после их исчерпания дальнейшее использование может требовать оплаты. Не включай платное пополнение без согласия взрослого.
- Регистрация и использование должны соответствовать возрастным условиям Cerebras и местным правилам.

## Ограничения прототипа

- Qwen 0.5B — небольшая модель для офлайн-доступа; качество заметно ниже современных облачных моделей.
- Онлайн-режим требует серверного `CEREBRAS_API_KEY`; доступность и остаток бесплатных кредитов зависят от аккаунта провайдера.
- История синхронизируется после входа; без входа переписка остаётся только в браузере.
